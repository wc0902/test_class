# Python 數學運算

## 1. 基本運算子

| 運算子 | 說明 | 範例 | 結果 |
| ------ | ---- | ---- | ---- |
| `+` | 加法 | `3 + 5` | `8` |
| `-` | 減法 | `7 - 2` | `5` |
| `*` | 乘法 | `3 * 5` | `15` |
| `/` | 除法 | `10 / 3` | `3.333...` |
| `//` | 整數除法 | `10 // 3` | `3` |
| `%` | 取餘數 | `10 % 3` | `1` |
| `**` | 次方 | `2 ** 3` | `8` |

## 2. 運算子優先順序

跟數學課本一樣，Python 會先乘除後加減，括號可以改變順序。

```python
print(3 + 5 * 2)     # 13，先乘後加
print((3 + 5) * 2)   # 16，括號優先
```

優先順序：括號 `()` > 次方 `**` > 乘除 `*` `/` `//` `%` > 加減 `+` `-`

## 3. 資料型別

| 型別 | 說明 | 範例 |
| ---- | ---- | ---- |
| `int` | 整數 | `50` |
| `float` | 浮點數 | `50.5` |
| `str` | 字串 | `'robert'` |
| `bool` | 布林值 | `True` / `False` |

### 型別轉換

```python
print(int("5") + 5)   # 10，把字串 "5" 轉成整數再加
print(float(5))       # 5.0，整數轉成浮點數
```

## 4. 輸入與運算

使用 `input()` 取得使用者輸入，搭配 `int()` 或 `float()` 轉成數值。

```python
n = int(input("請輸入整數:"))
m = float(input("請輸入另一個數值"))
print(n, "*", m, "=", n * m)
```

## 5. 圓面積計算

使用 `math` 模組取得圓周率 `math.pi`。

```python
import math

radius = float(input("請輸入半徑:"))
area = radius ** 2 * math.pi
print("半徑:", radius, ", 圓面積=", area)
```
